# Tavern

Лёгкий и быстрый фронтенд для ролевых чатов с ИИ. Функционал как у SillyTavern, совместим с её
форматами (карточки PNG/JSON V2/V3, лорбуки, пресеты, чаты JSONL). Написан с нуля на Python.

Статус: ранняя разработка, готов каркас (этап 0). План: [docs/ROADMAP.md](docs/ROADMAP.md).

## Установка и запуск

**Android (Termux), Linux, macOS**

```bash
bash install.sh
./start.sh
```

**Windows** (нужен Python 3.11+)

```bat
start.bat
```

Интерфейс открывается в браузере: <http://127.0.0.1:8000/>.

В Termux поставьте `pkg install termux-api` и приложение Termux:API, тогда браузер откроется сам.
`start.sh` включает `termux-wake-lock`, чтобы Android не усыплял сервер во время ответа.

## Доступ с другого устройства

По умолчанию сервер принимает подключения только с этого устройства. Чтобы открыть доступ по
локальной сети, в `data/config.toml` укажите `host = "0.0.0.0"` (или запустите с
`--host 0.0.0.0`). При старте в консоли появится ссылка вида `http://IP:8000/login?token=...`.
Откройте её на другом устройстве один раз. Сменить токен: `python -m tavern token --rotate`.

Если сервер стоит за туннелем или обратным прокси, включите `remote_access = true`: тогда токен
требуется для всех запросов.

## Данные и откат

Все данные лежат в `data/`. Резервные копии:

```bash
python -m tavern backup create        # снимок сейчас
python -m tavern backup list
python -m tavern backup restore NAME  # сервер должен быть остановлен
```

Перед каждым обновлением схемы базы снимок делается автоматически.
`python -m tavern --sandbox` запускает приложение на временной копии данных: всё, что вы там
сделаете, удалится при выходе.
