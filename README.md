# White House

Фронтенд для ролевых чатов с ИИ. Запускается в Termux на телефоне и на компьютере, открывает карточки, лорбуки и пресеты из SillyTavern. Вы подключаете свою модель по API, а чаты и настройки хранятся у вас на устройстве.

Интерфейс пока только на русском.

## Установка

В Termux, Linux и macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/Okimar/white-house/main/get.sh | bash
white-house
```

В Windows (нужен [Python 3.11+](https://www.python.org/downloads/)):

```bat
git clone https://github.com/Okimar/white-house.git
cd white-house
start.bat
```

Затем откройте в браузере <http://127.0.0.1:8000/>. Чтобы обновиться в Termux, Linux или macOS, выполните строку с `curl` ещё раз: данные останутся на месте.

Node.js не нужен. Все зависимости написаны на чистом Python, поэтому на телефоне ничего не компилируется.

## Первые шаги

1. Нажмите «Добавить подключение», выберите сервис, укажите ключ и модель.
2. В разделе «Персонажи» создайте персонажа или загрузите карточку.
3. Нажмите на персонажа и выберите «Новый чат».

## Что умеет

### Чат

Ответ приходит потоком, и его можно остановить. Если страницу перезагрузить, поток продолжится. У каждого ответа можно попросить другой вариант и листать варианты стрелками. Сообщения можно править, удалять, скрывать от модели и менять им роль.

От любого сообщения отходит новая ветка, старая при этом остаётся. Поиск переводит к найденному сообщению, даже если оно ещё не загружено. Длинные чаты подгружаются частями, пока вы листаете вверх. Чат можно выгрузить в файл и загрузить обратно.

Заметки автора бывают разовыми, скрытыми и видимыми. Они задаются для всех чатов, для персонажа или для одного чата. Работают макросы `{{char}}`, `{{user}}`, `{{random}}`, `{{roll}}` и переменные.

Окно «Что видела модель» показывает промпт любого ответа по частям.

### Несколько персонажей

Отдельного режима для групп нет: персонажа можно добавить в любой чат. Следующего говорящего определяют имена в тексте и болтливость, очередь или сама модель, а можно выбирать его вручную. Участнику можно велеть молчать и настроить, что он знает об остальных.

Есть ходы из нескольких реплик: «пусть поговорят» с пределом реплик, ответ всех сразу и рассказчик.

### Персонажи и лорбуки

Персонаж и лорбук устроены как дерево блоков, которое можно редактировать на карте. Блок попадает в промпт всегда или раз в несколько ответов, по ключевым словам с учётом русских окончаний, по смыслу или по ссылке из другого блока. У блока есть шанс срабатывания и удержание на несколько ответов, а общий объём ограничен бюджетом токенов.

Лорбук включается глобально, для чата или для персонажа. Каждая правка карточки сохраняется в истории: её можно отменить или вернуться к старой версии.

### Пресеты и шаблоны

Пресет собирается из блоков, причём у каждого чата может быть свой. Группа «один из» оставляет включённым только один блок. Блок «Размышление» просит модель подумать перед ответом. Текст в `<thinking>` убирается из ответа в отдельную сворачиваемую строку, и вы решаете, показывать ли его и отправлять ли обратно модели.

Для text completion есть instruct-шаблоны: встроенные, свои и подбираемые по имени модели.

### Подключения

В каталоге есть известные сервисы с готовыми адресами. Подойдёт и любой OpenAI-совместимый сервер, в том числе локальный. Gemini и Claude работают через собственные протоколы, поэтому с ними доступны размышление, картинки и поиск в сети.

- На одно подключение можно завести несколько ключей, у каждого свой прокси.
- Запасные шаги срабатывают, если модель упала, вернула пустой ответ или отказала: другая модель, подключение или ключ.
- Профиль хранит подключение, модель, настройки и пресет, и переключается одним действием.
- Один запрос можно отправить сразу в несколько моделей: победит первая ответившая, либо вы выберете ответ сами.
- Проверка показывает, какие настройки принимает конкретная модель.

### Расход

Токены и деньги считаются по сообщению, чату, дню и месяцу. Цена берётся у сервиса или задаётся вручную, валюта пересчитывается по вашему курсу. Лимит может предупредить или остановить запросы.

### Помощник

Окно помощника работает поверх чата. Он собирает лорбуки и персонажей, меняет тему и настройки, читает чаты и то, что видела модель. Большую работу он ведёт по шагам: задаёт вопросы, показывает план, выполняет пункты, а отдельная модель-критик проверяет результат. На каждую из этих ролей можно назначить свою модель. Поддержка вызова инструментов от модели не требуется.

Всё, что изменил помощник, отменяется. Перед удалением он спрашивает разрешение, у него есть свои лимиты расхода. Инструкции для разных видов работы можно править и дополнять на отдельной вкладке.

### Дополнения

Дополнения ставятся из файла или с GitHub. Перед первым запуском и после изменения файлов их нужно подтвердить, а доступ к моделям выдаётся отдельно и с лимитами. Встроены три:

- кубики (`/roll 2d6`);
- перевод через Google Translate;
- дерево мыслей: перед ответом несколько «думальщиков» обсуждают сцену, а их рассуждения видны под сообщением или в боковой панели.

### Темы

Встроены основная, светлая, тёмная и sakura, а свои ставятся папкой или одним файлом `.tavern-theme`. Тема может менять цвета и картинки, добавлять сцену за чатом и анимации. Скрипт темы запускается только после вашего подтверждения, а `/?safe` открывает страницу без него. У персонажа может быть своя тема.

### Копии данных

Копии всей папки данных делаются при запуске, по расписанию, вручную и перед рискованными действиями. Восстановить копию можно без перезапуска сервера. Копии также загружаются на Google Drive через ваш собственный OAuth-клиент.

Секреты в копии не попадают, поэтому после восстановления на новом устройстве ключи придётся ввести заново.

```bash
python -m tavern backup create        # снимок сейчас
python -m tavern backup list
python -m tavern backup restore NAME  # сервер должен быть остановлен
python -m tavern doctor --fix         # проверить и починить данные
python -m tavern --sandbox            # запустить на временной копии данных
```

## Совместимость с SillyTavern

Открываются карточки PNG и JSON версий V1, V2 и V3, миры, пресеты Chat Completion и instruct-шаблоны. Всё это можно выгрузить обратно в формате SillyTavern.

Пока нет:

- импорта чатов и всей папки SillyTavern;
- regex-скриптов и суммаризации;
- поддержки расширений SillyTavern;
- английского интерфейса.

## Доступ с другого устройства

По умолчанию сервер слушает только это устройство. Для доступа по локальной сети укажите `host = "0.0.0.0"` в `data/config.toml` или запустите с `--host 0.0.0.0`. При старте появится ссылка `http://IP:8000/login?token=...`: откройте её на другом устройстве один раз. Сменить токен можно командой `python -m tavern token --rotate`.

## Разработка

Сервер написан на Starlette и SQLite, страница на Preact без сборки. Начните с [AGENTS.md](AGENTS.md), план лежит в [docs/ROADMAP.md](docs/ROADMAP.md). Тесты запускаются командой `python -m pytest`.

Код написан с нуля по публичным форматам данных, кода SillyTavern в нём нет.
