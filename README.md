# White House

Фронтенд для ролевых чатов с ИИ. Читает карточки и лорбуки SillyTavern, код написан с нуля.
Работает на компьютере и в Termux, интерфейс не лагает даже на длинных чатах.

## ⚡ Установка одной командой (чистый Termux)

Откройте Termux и вставьте одну строку:

```bash
curl -fsSL https://raw.githubusercontent.com/Okimar/white-house/main/get.sh | bash
```

Скрипт сам поставит `git` и `python`, скачает программу, настроит всё нужное и создаст команду запуска.
Компилировать ничего не нужно: только готовые пакеты, поэтому ставится быстро.

Потом запускайте так:

```bash
white-house
```

и откройте в браузере <http://127.0.0.1:8000/>. Чтобы обновиться, выполните ту же строку ещё раз:
ваши данные останутся на месте.

> Совет: `pkg install termux-api` и приложение Termux:API помогут открывать браузер сами.

<details>
<summary><b>Windows, Linux, macOS</b></summary>

## Чем отличается от SillyTavern

- **Бэкенд на Python, интерфейс без сборки.** Нет Node.js и `npm install`. Зависимости только чистый Python, поэтому в Termux всё ставится одной строкой и ничего не компилируется.
- **Не лагает.** Список сообщений виртуальный: в DOM только то, что на экране, поэтому чат на тысячи сообщений прокручивается так же, как пустой. Проверено на телефоне.
- **Несколько персонажей в любом чате, без отдельного режима.** Кто говорит следующим, решают имена, болтливость, очередь, сама модель или вы. Есть ходы из нескольких реплик («пусть поговорят», все сразу) и рассказчик.
- **Персонаж и лорбук устроены как дерево блоков.** Блок срабатывает всегда, по ключевым словам (с русскими окончаниями), по смыслу или цепочкой от другого блока. У блоков есть группы и бюджет токенов. Любая правка карточки откатывается.
- **Несколько ключей на одно подключение**, у каждого свой прокси. Если модель упала, чат продолжит другая (запасные варианты). Можно отправить запрос сразу в несколько моделей, побеждает первая.
- **Gemini и Claude через их собственные протоколы**, а не только OpenAI-совместимые: размышление, картинки, поиск в сети, структурированный вывод.
- **Учёт расходов:** токены и деньги по сообщению, чату, дню и месяцу, с лимитами.
- **Помощник в самом приложении.** Создаёт лорбуки и персонажей, меняет темы, читает чат. Работает и со слабыми моделями. Любое его изменение откатывается.
- **Дерево мыслей:** перед ответом несколько «думальщиков» обсуждают сцену, и вы видите живое дерево под ответом.
- **Копии всей папки данных** по расписанию и перед рискованными действиями, в том числе на Google Drive через ваш OAuth-клиент. Команда `doctor` проверяет и чинит данные.
- **Темы** папкой или одним файлом `.tavern-theme`; **дополнения** ставятся из файла или с GitHub, каждое нужно подтвердить.

Совместимо: карточки PNG/JSON V1–V3, миры SillyTavern, пресеты, instruct-шаблоны.

**Чего пока нет:** импорта чатов SillyTavern (запланирован).

## 🚀 Первые шаги

1. Нажмите «Добавить подключение», выберите сервис, укажите ключ и модель.
2. В «Персонажах» нажмите «+» или загрузите карточку.
3. Нажмите на персонажа → «Новый чат». Готово!

## 📱 Доступ с другого устройства

По умолчанию сервер слушает только это устройство. Для доступа по локальной сети:
`host = "0.0.0.0"` в `data/config.toml` или `--host 0.0.0.0`. При старте появится ссылка
`http://IP:8000/login?token=...`: откройте её на другом устройстве один раз.
Сменить токен: `python -m tavern token --rotate`.

## 💾 Данные и откат

Всё лежит в `data/`.

```bash
python -m tavern backup create        # снимок сейчас
python -m tavern backup list
python -m tavern backup restore NAME  # сервер должен быть остановлен
python -m tavern doctor --fix         # проверить и починить
python -m tavern --sandbox            # попробовать на временной копии данных
```
