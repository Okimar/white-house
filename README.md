## ⚡ Установка одной командой (чистый Termux)

Откройте Termux и вставьте одну строку:

```bash
curl -fsSL https://raw.githubusercontent.com/Okimar/white-house/main/get.sh | bash
```

Скрипт сам поставит `git` и `python`, скачает программу, настроит всё нужное и создаст команду запуска.
Компилировать ничего не нужно: только готовые пакеты, поэтому ставится быстро.

Потом запускайте так:

```bash
white-house
```

и откройте в браузере <http://127.0.0.1:8000/>. Чтобы обновиться, выполните ту же строку ещё раз:
ваши данные останутся на месте.

> Совет: `pkg install termux-api` и приложение Termux:API помогут открывать браузер сами.

<details>
<summary><b>Windows, Linux, macOS</b></summary>

**Windows** (нужен [Python 3.11+](https://www.python.org/downloads/)):

```bat
git clone https://github.com/Okimar/white-house.git
cd white-house
start.bat
```

**Linux / macOS**:

```bash
curl -fsSL https://raw.githubusercontent.com/Okimar/white-house/main/get.sh | bash
```

Первый запуск сам ставит всё нужное.

## ✨ Что умеет White House

### 💬 Чаты, в которых приятно жить
- **Несколько персонажей в любом чате.** Кто говорит следующим, решают имена, болтливость, очередь, сама модель или вы вручную.
- **Ходы из нескольких реплик:** «пусть поговорят», все сразу, рассказчик.
- **Ветки и свайпы.** Перегенерируйте, продолжайте, говорите за себя через «impersonate».
- **Заметки автора** (общие, на персонажа, на чат) и **«что модель увидела»** с полной историей промптов.
- Плавная прокрутка тысяч сообщений.

### 🧙 Персонажи и миры
- Карточки **PNG/JSON V1/V2/V3**: импорт и экспорт, совместимо с SillyTavern.
- **Дерево-«пузырьки»** персонажа: всегда, по ключевым словам (с русскими окончаниями), по смыслу, цепочки, группы и бюджет токенов.
- **Лорбуки** глобальные, на чат и на персонажа; миры SillyTavern читаются и пишутся.
- Бесконечная история правок карточки с откатом.

### 🔌 Любая модель
- **Gemini, Claude, OpenAI-совместимые** сервисы и ваши локальные серверы.
- Несколько ключей на подключение, у каждого свой прокси; переключение на следующий ключ при сбое.
- Размышление, картинки, поиск в сети, структурированный вывод.
- **Профили** подключений и **запасные варианты**: если модель упала, чат продолжит другой.
- **Параллельные запросы:** несколько моделей сразу, побеждает первая.
- Шаблоны instruct для текстовых моделей, настройки под каждую.

### 🌳 Дерево мыслей
Перед ответом «думальщики» обсуждают сцену по кругу, и вы видите живое дерево мыслей под ответом
или в боковой панели. Для каждого персонажа свои мыслители.

### 🪄 Помощник внутри приложения
Окно помощника сделает за вас то, что умеет сам интерфейс: создаст лорбук, соберёт персонажа,
поменяет тему, прочитает чат. Работает даже со слабыми моделями (вопросы → план → шаги → проверка
критиком). **Любое изменение можно откатить.**

### 🎨 Ваш вид
- Темы папкой или одним файлом `.tavern-theme`: цвета, картинки, анимации, скрипты эффектов.
- Просьба текстом: «сделай красиво, добавь сакуру» — и помощник оформит.
- Адаптивно для телефона и планшета.

### 🧩 Дополнения
Подтверждаете каждое дополнение сами. Ставятся из файла или с GitHub. Есть встроенные: кубики
`/roll`, Google-перевод, дерево мыслей. Свои пишутся просто.

### 💰 Расходы под контролем
Токены и доллары на сообщение, чат, день и месяц; лимиты с предупреждением или остановкой.

### 🛡️ Данные в безопасности
- **Копии всей папки данных** по расписанию и перед рискованными действиями, восстановление «вживую».
- **Копии на Google Drive** через ваш собственный OAuth-клиент.
- «Доктор» проверяет и чинит данные.
- Только локальный доступ по умолчанию; удалённый только по токену. Ключи не попадают ни в браузер, ни в логи.

## 🚀 Первые шаги

1. Нажмите «Добавить подключение», выберите сервис, укажите ключ и модель.
2. В «Персонажах» нажмите «+» или загрузите карточку.
3. Нажмите на персонажа → «Новый чат». Готово!

## 📱 Доступ с другого устройства

По умолчанию сервер слушает только это устройство. Для доступа по локальной сети:
`host = "0.0.0.0"` в `data/config.toml` или `--host 0.0.0.0`. При старте появится ссылка
`http://IP:8000/login?token=...`: откройте её на другом устройстве один раз.
Сменить токен: `python -m tavern token --rotate`.

## 💾 Данные и откат

Всё лежит в `data/`.

```bash
python -m tavern backup create        # снимок сейчас
python -m tavern backup list
python -m tavern backup restore NAME  # сервер должен быть остановлен
python -m tavern doctor --fix         # проверить и починить
python -m tavern --sandbox            # попробовать на временной копии данных
```
